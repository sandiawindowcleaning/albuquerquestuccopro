# albuquerquestuccopro.com

Lead-gen site for Albuquerque Stucco. React + Vite + TypeScript + Tailwind,
prerendered to static HTML and deployed on Netlify.

```
npm install
npm run dev      # local development
npm run build    # production build + SEO verification (what Netlify runs)
```

All business details live in `src/config/`. See `CLAUDE.md` for architecture,
rules and common tasks.
